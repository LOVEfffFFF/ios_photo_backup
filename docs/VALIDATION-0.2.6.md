## 50% 强度样本的时间实验：失败

用户在上述普通恢复副本上将效果强度改为 50%，保存、备份并重新连接。只读预检确认当前配方已变为 `com.apple.photo/1.9.1`，实际附件字节与备份相同，编辑时间与拍摄时间不同。随后仅执行一次 `mainResourceImportDate`，创建一份新副本，并分别独立回读新副本、100% 原片和 50% 源片。

- 拍摄时间为北京时间 2026-10-20 06:28:05.2；源片实际 plist 编辑时间为 06:39:47，新副本变为 06:28:05。主 DNG 导入时间选项未能保留原编辑时间。
- 源片与副本的完整 plist 均为 1,086 字节，差异只有 `adjustmentTimestamp`；仅在内存中替换该日期后，完整字节精确相等。独立回读再次确认副本字节和日期。
- DNG 61,018,166 字节和本次渲染 JPEG 12,073,383 字节，源片、备份、下载、副本及独立回读的 SHA256 相同；拍摄时间含小数秒保留。
- 完整压缩配方 332 字节、解压 JSON 611 字节相同，保留 `3DSilverplate` 强度 0.5 和 RAW 显影操作。App 尚未映射这个效果名称，本次副本的系统相册 UI 未人工验收；不据此声称完整恢复。
- 100% 原片及 50% 源片的资源、实际编辑附件和拍摄时间与各自预检证据一致，均仍保留。没有修改备份，没有删除任何照片。

后台控制器先记录提交意图和任务编号，超时或失去响应不会自动再导入一份。本轮没有重复执行 0.2.5 的六组测试。实际设备数据和完整证据保留在 Git 之外。

0.2.7 根据后续实现线索增加另一项独立实验，见 [实验计划](TIMESTAMP-EXPERIMENTS-0.2.7.md)。这不改变 0.2.6 的失败结论，也没有在普通恢复中启用时间修正。
