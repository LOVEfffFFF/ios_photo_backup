# 备份确认与补传

本轮开发在独立仓库中进行，原项目未参与修改、测试或运行。测试只使用临时目录中的合成字节，不使用真实相册或现有接收数据。

## 已实现

- 接收端重新读取上传临时文件计算 SHA256，并核对客户端资源哈希；不符返回 422，不进入正式文件或清单。`-NoHash` 不会关闭上传校验。
- 同路径文件重新比较实际内容；相同内容可重试，不同内容返回 409，保留原文件和单独的冲突副本。
- 文件与清单均确认后才返回成功。清单写入使用刷新到磁盘的文件流；失败返回 500，重试可以补记已保存文件。中断留下的半行不会吞掉下一条记录。
- 回执包含路径、大小、哈希、校验状态和清单确认；手机端逐项验证，旧版或异常 HTTP 200 不能记为成功。
- 每次备份重新导出并核验所选范围。手机记录、拍摄时间与像素尺寸均不再直接排除资产，电脑端文件被删除后可重新上传。
- 所有资源都得到确认后才写入本机完整记录。附件失败、资源缺失、重复导出路径、未知资源数量及 Live Photo 配对视频缺失都会保留为失败并可重试。
- Live Photo 使用同次导出的配对资源，避免重复上传及静默降级为普通图片。视频与照片共用原始 PhotoKit 资源导出，不再通过视频导出会话重新封装。
- 文件名使用完整相册标识的哈希前 128 位，避免原标识共享前缀时撞名。同角色附件在原生导出时另加资源序号，避免并行写入同一个暂存文件。
- 本机重复记录读取时取相册标识的最后一条；失败结束不会显示 100% 完成或宣称范围内全部备份。
- 2026-10-19 真机采样暴露并修复了 Windows 临时路径过长：ProRAW 编辑附件最终路径为 222 字符，旧上传临时名追加 GUID 后达到 267 字符，导致 Windows PowerShell 5.1 创建文件失败。临时文件与冲突副本改用同目录下的短名称，不改变正式资源路径、清单或既有文件。正在运行的接收端需要重启后才会加载修复；手机可重新备份补齐缺失附件。

## 验证方式

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\receiver-upload.tests.ps1
```

该检查从生产脚本提取函数，不启动监听、不注册 ACL、不修改防火墙。合成数据默认写入系统临时目录，可通过 `-TestRoot` 指定独立测试目录。

接收端当前共 28 项合成检查通过。新增长路径用例在修复前复现 5 项失败，修复后验证 plist 与 AAE 附件保存、重复上传、冲突内容保留、哈希不符拒绝及暂存清理。

用户重启接收端后，三份 iPhone 14 Pro Max / iOS 17.7.2 的 ProRAW 样本已补齐附件；每份包含 DNG、当前编辑 plist、相机 AAE、渲染 JPEG。12 个文件的实际大小与 SHA256 均与清单一致。当前编辑配方为 `com.apple.photo / 1.9.1`，其数据经 raw DEFLATE 解压后为 JSON，可分别读到 `3DVivid`、`3DDramatic` 以及无 `Effect` 项三种状态。三份相机 AAE 则均保留同一较早的 `3DVividWarm` 配方，说明相机 AAE 哈希一致不能证明当前滤镜相同。0.2.0 已将按版本限制的解析集成 App，恢复效果和其他配方版本仍需真机验证，详见 [PHOTO-EDITS.md](PHOTO-EDITS.md)。

在 Flutter 环境运行 `flutter pub get --enforce-lockfile`、`flutter analyze --no-fatal-infos --no-fatal-warnings` 和 `flutter test`。锁文件来自本仓库第一轮通过分析和测试的 GitHub runner 实际依赖解析。手动 iOS 构建流程同时执行 Windows 检查、Dart 分析和测试，通过后才打包，并校验独立应用标识。

## 仍需完成的验收

目前采用重新导出并传输资源的保守核验方式，相同内容只省去重复保存，**不节省网络传输**。大库性能优化需要在同样严格的确认条件下设计接收端资源查询协议。

同一资产编辑后产生不同内容时会报告冲突，不会自动建立可恢复的历史版本。同一 Live Photo 出现多份配对视频时会报告未完成，尚未解决这些资源的版本关系。数量一致只是当前的必要条件，完整的逐资源身份协议、资产级完成标记和跨设备关系仍属于下一阶段。

新文件名与导入基线不同，已使用独立初始版本写入的文件可能保留为旧路径；不会自动迁移或删除它们。

0.2.0 改用公开资源类型恢复当前配方及渲染图，并在往返验证中逐项读取原图与新副本；缺少回读不再以下载文件代替。部分导入有单独警告和状态记录。iOS 编译通过不能代替真机验证；普通图片、编辑视频、Live Photo、ProRAW、iCloud 原件和中断重试仍需在测试素材上验收。
