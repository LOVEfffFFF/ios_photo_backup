## 本版功能及限制

- 对样本结构显示当前鲜明、反差色、无显式滤镜项；较早相机鲜暖色单独显示。未知配方显示未知。
- 以公开 PhotoKit 类型复制 DNG、当前 adjustmentData 和 fullSizePhoto；导入后逐项回读。系统拒绝组合时报告失败，不静默降级。
- 样本相机 AAE 未确认公开创建类型，保存在电脑，省略导入会明确标为部分恢复。
- 未声称系统相册已经识别恢复的可编辑滤镜。原始资源/配方回读与系统界面效果、RAW 标记、可编辑性是不同检查。
- 批量恢复仍有继承的时间/类型/尺寸指纹判断；普通无附件照片、视频的批量恢复未改为全面回读。先按 [编辑数据说明](PHOTO-EDITS.md) 逐张验收 ProRAW。
