# 实时真机调试（0.2.4）

手机主动连接电脑上的独立调试服务。备份接收服务仍使用 18080；调试服务默认使用 18081，不读取或改写接收端的数据文件。往返任务通过既有接收服务下载备份、创建新副本并实际回读。

## 手机与电脑

1. 电脑安装 Node.js 20 或更新版本，在独立仓库的 debug-bridge 目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start-debug.ps1`。服务隐藏运行；窗口输出电脑地址、6 位数字连接码及连接文件位置。必要时仅允许 Windows 专用网络上的此端口入站连接。
2. 安装 0.2.4 独立版，保留现有备份服务器设置。主页右上角点虫子图标，进入“实时调试”。
3. 填调试地址和连接码，勾选 1–10 张已备份照片。允许往返测试时会创建副本，本次连接最多十次；只需读取时可取消该选项。点“开启本次调试”。
4. 保持此页在前台。电脑可读取资源、导出完整编辑附件、核对哈希、执行往返测试，并查看持续回传的日志末尾。切到后台会暂停接收新任务，已开始的操作可能仍在执行或被系统暂停；回到前台后继续传回结果。
5. 结束时点“断开调试”。正在执行的任务会先结束并传回结果。断网时未送达结果先保存在手机 Documents/debug_last_result.json；新连接不自动重发旧任务，也不会自动重做导入。断开后可在本页清理记录的调试副本，需用户及系统确认。

服务和连接码默认 7 天后过期，期间主动断开后可使用同一码重新连接；服务进程需持续运行，重启服务会生成新码。手机会显示实际到期日期。新版同时兼容旧版 16 位连接码。连接码每分钟最多允许 10 次错误尝试，达到上限需等待下一分钟。保持手机与电脑处于可信的同一局域网。此通道使用与现有局域网接收服务相同的 HTTP 传输方式。

## 电脑操作

连接文件在 `debug-bridge/data/live-…/connection.json`，其中有单独的电脑控制密钥。该文件不要分享。以下命令在独立仓库根目录运行，CONNECTION_FILE 替换成启动时显示的完整路径：

```text
node debug-bridge/control.cjs CONNECTION_FILE status
node debug-bridge/control.cjs CONNECTION_FILE inspect asset-1
node debug-bridge/control.cjs CONNECTION_FILE roundTrip asset-1
node debug-bridge/control.cjs CONNECTION_FILE job JOB_ID
node debug-bridge/control.cjs CONNECTION_FILE logs
```

status 给出所选照片与 asset-N 对应关系、在线状态、任务状态及新副本的 copy-N 标识。一次只接受一项任务；job 可读取最终结果。inspect 也支持本次产生的 copy-N，但不能对副本再发起往返导入。

结果写在服务独立目录的 JOB_ID.json。strictBytesMatch 保留严格校验；传输任务成功不等于照片校验通过。实际 XML/二进制 plist 的原始字节保存在 currentAdjustmentEnvelope.resourceData.base64，配有长度与 SHA256，可独立校验、解包和逐字段比较；相机附件单列为 cameraAdjustmentEnvelope。读取失败、资源大于 1 MiB 或未知配方不会显示为通过。

## 行为边界

- 手机显式开启，本次连接仅访问所选照片及由该连接创建的副本。没有远程删除、修改原图、批量恢复或任意执行代码的接口。
- 电脑控制接口只接受本机回环地址、正确的 Host 和独立控制密钥；不开放浏览器跨域访问。手机端使用不同的连接码。
- 任务领取后不自动重新投递。结果回传可以重试；领取响应丢失、App 中止或更换连接时，不能把未知状态当作测试通过，也不能静默再创建副本。
- 副本 ID 在导入返回后尽早写入手机的独立记录，重启后仍可清理；不保证在系统提交与写入记录之间发生进程终止时绝无未记账副本。
- 此通道操作本 App 的 PhotoKit 功能，不能代替系统相册的 RAW 标记、还原按钮和编辑面板目视验收，也不能更新手机端代码；新增测试能力仍需安装新版。
- 真实资源、日志、连接凭据、任务结果都留在被 Git 忽略的目录。自动化检查只使用合成数据。

0.2.3 停用 0.2.2 已在真机失败的分步时间实验，保留拍摄时间回读和附件字节差异。它增加调试能力，尚未修复系统重写编辑时间的问题。
